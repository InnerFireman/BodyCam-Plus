2. Extract the archive using password `2026`
3. Run the utility as Administrator
4. Launch BodyCam
5. Press INSERT to open the menu

1. Open the **Combat** tab
2. Enable **Aimbot** and set hotkey
3. Adjust FOV and smoothness
4. Enable **Triggerbot** if needed
5. Toggle **No Recoil** and **No Spread**

1. Open the **Visuals** tab
2. Enable **ESP** for players
3. Toggle **Wallhack** and **Health Bars**
4. Enable **Skeleton ESP** if needed
5. Set max distance

## Movement

1. Open the **Movement** tab
2. Enable **Speed Hack** and set multiplier
3. Enable **Super Jump** and **Bunny Hop**
4. Toggle **No Fall Damage**

## Camera

1. Open the **Camera** tab
2. Enable **No Flash** and **No Blur**
3. Enable **No Shake** and **No Fog**
4. Adjust **FOV Changer** if needed
5. Enable **Night Vision** for dark areas

## Config

1. Open the **Config** tab
2. Click **Save** to store current settings
3. Click **Load** to restore a profile
4. Use **Streamproof** to hide overlay
